# Contributing

Goose Discord Bot is an open source project where development happens in the open on our [GitHub repository](https://github.com/80PercentLean/goose-discord-bot).

We welcome anyone to contribute! Whether you'd like to directly work on the codebase or suggest new features, we'd love your involvement!

If you have any questions or feature suggestions, we have [GitHub Discussions open for that on the Cupertino PoGO Map GitHub repository](https://github.com/80PercentLean/cupertino-pogo-map/discussions).

If you'd like to contribute code, simply [create a pull request](https://github.com/80PercentLean/goose-discord-bot/pulls) and we'll review it when we can.

To see what technologies we use, read the ["Technology Overview" section in `README.md`](../README.md#technology-overview).
